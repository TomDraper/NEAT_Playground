A place to put whatever explorations into the NEAT python library I want to play with.

There is no guarantee anything will work right now.

Instructions to Run:
Assumes you are using VSCode and on Windows. Linux/Mac will require different venv activations.
1. Download and place wherever you like.
2. Open in VSCode.
3. Create a new virtual environment (As a folder called venv):
```python -m venv venv```
4. Activate virtual environment:
```venv/Scripts/Activate.ps1```
5. Install Requirements
```pip install -r requirements.txt```
6. Run src/main.py via VSCode button or:
```python src/neat_playground/main.py```
